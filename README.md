# KPI Dashboard - SUPORTE 

Projeto para análise, monitoramento e visualização de **Key Performance Indicators (KPIs)**, permitindo acompanhar métricas importantes por meio de consultas, processamento de dados e dashboards interativos.

## Objetivo

Centralizar indicadores de desempenho em um único ambiente, facilitando a análise de dados e apoiando a tomada de decisões.

## Funcionalidades

- Coleta de dados de múltiplas fontes
- Processamento e limpeza dos dados
- Cálculo automatizado de KPIs
- Visualização de indicadores em dashboards
- Atualização periódica dos dados
- Organização modular do código

## Estrutura do Projeto

```text

```

## KPIs Analisados

| Indicador | Descrição |
|---|---|
| Receita total | Soma da receita no período analisado |
| Crescimento mensal | Variação percentual mês a mês |
| Número de clientes | Total de clientes ativos |
| Ticket médio | Valor médio por transação/cliente |
| Taxa de conversão | % de leads convertidos em clientes |
| Churn | Taxa de cancelamento/perda de clientes |
| Tempo médio de atendimento | Duração média dos atendimentos |
| NPS | Índice de satisfação do cliente |

## Fontes de Dados
